# v1.0.0 — Лабораторная работа №1: Julia

**Версия:** 1.0.0  
**Дата:** 9 сентября 2026 г.

## Описание

Первая лабораторная работа посвящена установке и настройке Julia и Jupyter Lab,
созданию воспроизводимого проекта `DrWatson` и изучению основных конструкций
языка Julia. В работе выполнены примеры с типами данных, преобразованиями,
функциями, вводом-выводом, векторами и матрицами, проведён параметрический
расчёт и решён пример обыкновенного дифференциального уравнения.

## Цели работы

1. Подготовить Julia и Jupyter Lab к выполнению вычислений.
2. Создать воспроизводимое окружение проекта.
3. Изучить базовые типы, функции и операции Julia.
4. Выполнить задания по вводу-выводу, `parse`, векторам и матрицам.
5. Провести расчёт для набора параметров и сохранить результаты.
6. Сформировать notebook, Quarto-документ, отчёт и презентацию.

## [1.0.0] - 2026-09-09

### Added

- Лабораторная работа №1 по установке, настройке и основам Julia.
- Воспроизводимый проект `DrWatson` с зафиксированным окружением Julia 1.12.5.
- Примеры типов, преобразований, функций, файлового ввода-вывода и `parse`.
- Примеры математических, логических, векторных и матричных операций.
- Параметрический расчёт с сохранением результатов в CSV и JLD2.
- Пример численного решения обыкновенного дифференциального уравнения.
- Literate-источник и производные форматы `.jl`, `.ipynb`, `.qmd` и `.html`.
- Автоматические тесты вычислений и структуры проекта.
- Отчёт в форматах Quarto, PDF и DOCX.
- Презентация в форматах Quarto, Beamer PDF и reveal.js HTML.
- Скриншоты выполнения, вычислительный график и полный архив `lab01.zip`.

### Changed

- Шаблоны отчёта и презентации заполнены фактическими материалами лабораторной.
- Для Julia-листингов подключён моноширинный шрифт с поддержкой кириллицы.
- Локальные рабочие материалы вынесены в исключённый из Git каталог `no-commit`.

### Fixed

- Исправлена настройка IJulia для актуального системного Jupyter.
- Увеличен порог ожидания медленных загрузок бинарных артефактов Julia.
- Устранены переполнения строк в отчёте и слайдах.
